BẬT TÍNH NĂNG HỘI VIÊN TỰ CẬP NHẬT HỒ SƠ

Cập nhật: 15/09/2026 (chuyển từ đường dẫn riêng sang tài khoản đăng nhập)

Phần lập trình đã xong và đã đưa lên web. Những bước dưới đây làm bằng tay vì
liên quan tới tài khoản và khoá bí mật. Bước 1-3 đã làm ngày 10/09/2026, chỉ
phải làm lại khi dựng web ở chỗ mới.


LƯU Ý TRƯỚC KHI BẮT ĐẦU

Khi dán khoá vào terminal, dùng CHUỘT PHẢI để dán, đừng bấm Ctrl+V. Lần trước
Ctrl+V đã chèn nhầm ký tự điều khiển làm khoá hỏng.

Dán khoá bí mật xong màn hình sẽ không hiện gì cả. Đó là bình thường, terminal
cố tình giấu. Cứ dán rồi Enter.


BƯỚC 1 — TẠO KHOÁ CHO MÁY CHỦ GHI VÀO KHO

Máy chủ cần quyền ghi vào kho GitHub để lưu hồ sơ hộ hội viên.

1. Vào https://github.com/settings/personal-access-tokens/new
2. Điền:
   - Token name:        clb-cap-nhat-ho-so
   - Expiration:        chọn No expiration
                        (chọn thời hạn thì tới ngày đó tính năng sẽ ngừng chạy)
   - Repository access: chọn "Only select repositories"
                        rồi chọn kho clb-doanh-nhan-website
3. Kéo xuống mục "Repository permissions", tìm dòng "Contents",
   đổi từ "No access" sang "Read and write"
   (chỉ cần đúng một quyền này, các dòng khác để nguyên)
4. Bấm "Generate token" ở cuối trang
5. Copy chuỗi hiện ra. Nó chỉ hiện MỘT LẦN, đóng trang là mất.


BƯỚC 2 — NẠP KHOÁ VÀO CLOUDFLARE

Mở terminal tại thư mục website, chạy lần lượt:

    cd "D:\Hosting\Hao's Projects\CLB Doanh Nhan\website"

    npx wrangler pages secret put GITHUB_TOKEN --project-name clb-doanh-nhan-khanh-hoa

  → dán chuỗi vừa copy ở bước 1

    npx wrangler pages secret put GITHUB_REPO --project-name clb-doanh-nhan-khanh-hoa

  → gõ đúng dòng này:  ttledinhnguyen-cmd/clb-doanh-nhan-website


BƯỚC 3 — NỐI CLOUDFLARE VỚI KHO GITHUB

Việc này để mỗi khi có người bấm Lưu, Cloudflare tự dựng lại website.
Không làm bước này thì nội dung vẫn được lưu nhưng website sẽ không đổi.

1. Vào https://dash.cloudflare.com
2. Workers & Pages -> chọn dự án clb-doanh-nhan-khanh-hoa
3. Settings -> mục Build -> bấm nút bên cạnh dòng "Git repository"
4. Hộp thoại "Connect to a repository" hiện ra, điền:

   Git account              chọn tài khoản GitHub của anh
   Repository               clb-doanh-nhan-website
   Production branch        main
   Framework preset         Astro
   Build command            npm run build
   Build output directory   dist
   Root directory           để nguyên, không mở mục advanced

5. Bấm Connect

Từ lúc này trở đi không cần chạy lệnh deploy bằng tay nữa. Cứ có thay đổi
trong kho là Cloudflare tự dựng lại.


BƯỚC 4 — TẠO BẢNG TÀI KHOẢN VÀ TÀI KHOẢN QUẢN TRỊ ĐẦU TIÊN

    cd "D:\Hosting\Hao's Projects\CLB Doanh Nhan\website"
    npx wrangler d1 execute clb-doanh-nhan --remote -y --file schema/tai-khoan.sql
    npm run tai-khoan -- admin "Quản trị viên" --vai-tro admin --nap

Lệnh thứ ba KHÔNG in mật khẩu hay link ra màn hình. Nó ghi link đặt mật khẩu
vào file:

    rieng-tu\link-dat-mat-khau-admin.txt

Mở file, bấm link, tự chọn mật khẩu (ít nhất 10 ký tự) là xong. Link dùng
được một lần, hết hạn sau 7 ngày. Thư mục rieng-tu đã được loại khỏi Git.

Từ đó trở đi, tài khoản cho ban thư ký và hội viên tạo ngay trên web:

  1. Đăng nhập tài khoản quản trị ở https://kh-sg.com/dang-nhap
  2. Vào https://kh-sg.com/tai-khoan, mục "Tạo tài khoản"
  3. Chọn vai trò:
       Hội viên      chỉ sửa hồ sơ của mình (phải chọn đúng hồ sơ)
       Ban thư ký    sửa toàn bộ nội dung website
       Quản trị      như ban thư ký, thêm quyền quản lý tài khoản
  4. Bấm Tạo tài khoản, gửi riêng link đặt mật khẩu hiện ra cho người đó
     qua Zalo. Người nhận tự đặt mật khẩu; quản trị viên không biết mật khẩu
     của ai.


SAU KHI XONG

Đăng nhập thử bằng tài khoản quản trị, vào trang cập nhật sửa một chữ, bấm
Lưu, chờ khoảng 1-2 phút rồi xem trên web đã đổi chưa.


NHỮNG TÌNH HUỐNG HAY GẶP

Ai đó quên mật khẩu, hoặc nghi lộ mật khẩu:
  Vào /tai-khoan, bấm "Tạo link đặt mật khẩu" ở tài khoản đó rồi gửi link
  mới. Mật khẩu cũ mất tác dụng ngay, mọi thiết bị đang đăng nhập bị đăng xuất.

Link đặt mật khẩu hết hạn (3 ngày với link tạo trên web):
  Bấm lại "Tạo link đặt mật khẩu" để lấy link mới.

Quản trị viên quên mật khẩu mà không còn quản trị viên nào khác:
    npm run tai-khoan -- admin --dat-lai --nap
  rồi mở file rieng-tu\link-dat-mat-khau-admin.txt.

Có người thôi tham gia:
  Vào /tai-khoan, bấm Khoá (giữ lại tài khoản) hoặc Xoá. Xoá hội viên ở trang
  cập nhật thì tài khoản hội viên gắn với hồ sơ đó cũng tự bị khoá.

Đăng nhập sai nhiều lần:
  Sai quá 10 lần trong 15 phút thì bị chặn 15 phút, tính theo tên đăng nhập
  và theo mạng đang dùng. Chờ hết 15 phút là đăng nhập lại được.

Xem ai đã sửa gì:
  Vào /tai-khoan, mục "Nhật ký thao tác" và "Lượt đăng nhập gần đây".
  Lịch sử kho GitHub cũng ghi "— bởi <tên đăng nhập>" cuối mỗi lần lưu.
  Xem nhiều hơn:
    npx wrangler d1 execute clb-doanh-nhan --remote --command "SELECT luc, tai_khoan, doi_tuong, noi_dung FROM nhat_ky_thao_tac ORDER BY id DESC LIMIT 100"

Ai đó sửa hỏng hồ sơ:
  Mọi thay đổi đều lưu lịch sử trong kho GitHub, khôi phục được. Báo tôi.
