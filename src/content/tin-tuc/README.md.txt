Thư mục này chứa các bài viết của mục Tin tức.

- Mỗi bài là một file .md, tên file chính là đường dẫn trên web.
  Ví dụ: caravan-lan-11.md  ->  /tin-tuc/caravan-lan-11
- File bắt đầu bằng dấu gạch dưới (_) sẽ KHÔNG hiển thị trên web.
  Xem _mau-bai-viet.md để biết cấu trúc.
- Tên file nên viết không dấu, dùng gạch nối thay cho khoảng trắng.
